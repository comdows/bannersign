# 지자체별 현수막 게시대 신청 사이트 조사 (2026-07-18)

웹 검색 기반 조사 결과. **개발 환경 프록시가 해당 사이트 접속을 차단해 페이지 내용까지는
미검증** — 각 URL은 실제 방문으로 확인 후 `status`를 갱신할 것.

## 패턴

경기 지역 다수 지자체는 현수막 지정게시대 온라인 접수를 **한국옥외광고협회(KOAA) 지역
지부 도메인 `{약어}koaa.or.kr`** 로 운영한다 (수원 swkoaa, 용인 yikoaa, 오산 osankoaa).
단, 지자체마다 수탁처가 다르며 화성시는 **장애인 단체 수탁**으로 파악됨(사용자 확인).
서울·인천 쪽은 시설관리공단, 일부 지역은 새올 전자민원(eminwon) 경유.

## 게시대 위치 데이터 소스

- 공공데이터포털 **전국현수막게시대시설표준데이터**: https://www.data.go.kr/data/15129434/standard.do
- 경기데이터드림 **현수막지정게시대 현황**: https://data.gg.go.kr (경기도_현수막지정게시대 현황)
- → 크롤 전이라도 `board_sites` 초기 시드로 활용 가능 (external_id는 사이트 크롤로 매핑)
